☕ Coffee Sales Dashboard (Excel)
📌 Project Overview
This project involves building an interactive Excel dashboard to analyze the sales performance of a coffee shop across multiple store locations. It provides insights into customer footfall, revenue patterns, product performance, and time-based trends.

🧰 Tools Used
Microsoft Excel

Pivot Tables

Slicers & Timelines

Charts & Conditional Formatting

📊 Key Metrics & Insights
Total Revenue: $19,304.81

Total Footfall: 4,135 customers

Average Bill per Person: $4.67

Average Orders per Person: 1.4

Top Performing Product: Barista Espresso ($2,499.15)

Peak Ordering Time: 8 AM – 10 AM

Most Profitable Store: Hell’s Kitchen ($7,287.09)

Weekday-wise Order Volume

🎯 Objective
To uncover hidden patterns in customer behavior and product sales to support data-driven decisions for inventory, staffing, and promotions in a coffee retail setting.

📁 Project Deliverables
Excel file with fully interactive dashboard

Cleaned and structured sales data

Visual summaries for key performance indicators
